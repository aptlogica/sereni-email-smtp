# Versioning Policy

This project follows [Semantic Versioning 2.0.0](https://semver.org/).

## Format
Versions are in the form MAJOR.MINOR.PATCH (e.g., v1.2.3).

- MAJOR: incompatible API changes
- MINOR: backward-compatible functionality
- PATCH: backward-compatible bug fixes

## Release Process
- All releases are tagged with a version (vX.Y.Z)
- Changelog is updated for each release
- Pre-releases use suffixes (e.g., v1.2.3-beta.1)

## Rationale
Semantic versioning provides clarity and predictability for users and contributors.
